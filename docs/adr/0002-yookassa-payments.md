# Оплата через ЮKassa и возврат при сбое доставки

Для учебного проекта выбран тестовый магазин ЮKassa с оплатой в рублях на готовой странице. Одностадийная оплата позволяет сохранить существующий запуск кухни и доставки по событию `order.paid`. В отличие от двухстадийной схемы с заморозкой средств, если курьер не найден, потребуется отдельный полный возврат.

Попытку оплаты и ключ запроса сохраняем до вызова шлюза. При сбое повтор используем с тем же ключом в пределах срока идемпотентности. Уведомления сверяем с API ЮKassa. Оплату и событие для кухни и доставки фиксируем в одной транзакции PostgreSQL. Отмену заказа и задачу возврата тоже фиксируем вместе. Шлюз вызывается после завершения транзакции, поэтому сбой сети не мешает сохранить отмену и не удерживает блокировку заказа.

Цена решения — отдельный статус возврата и операция сверки, когда исход запроса остался неизвестным. После исчерпания повторов исход проверяют в ЮKassa, пока заказ защищён от второго платежа.

# Поиск в PostgreSQL и генерация через OpenRouter

Чат использует локальную multilingual-e5-small в формате ONNX INT8 и pgvector в существующей PostgreSQL. Это позволяет искать по русскоязычному меню на CPU и хранить векторы рядом с исходными данными. Для небольшого меню достаточно точного поиска по косинусному расстоянию. Если сменить модель эмбеддингов, нужно пересчитать векторы и при изменении их размера обновить схему.

Для генерации выбран маршрутизатор `openrouter/free`, который подбирает доступную бесплатную модель для каждого запроса. Идентификатор модели можно закрепить настройкой `OPENROUTER_MODEL`. Бесплатные запросы ограничены квотой. OpenRouter получает вопрос, найденные источники, недавние реплики и краткую сводку активных заказов или последнего заказа при отсутствии активных. Сводка формируется из PostgreSQL после проверки JWT. Ответы о статусе и составе формирует модель по свежей сводке и переписке. Сервер проверяет владельца указанного заказа перед вызовом модели.
